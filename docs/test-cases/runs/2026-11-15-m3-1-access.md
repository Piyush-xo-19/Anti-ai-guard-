# M3.1 Windows 11 permission results

The clean-source run used commit
`de927433c61cee982ecc72626d5cde4b475c56e6` on Windows 11 build
26300.9974 (registry release 26H2), with an x64 probe and a standard-user
token. The enabled administrator and Performance Log Users roles and the
built-in service identity checks all returned false.

| Case | Actual result |
| --- | --- |
| M3.1-CONSENT | PASS. The runner required its consent switch, and each probe refused missing runtime opt-in with exit 2 and empty output. |
| M3.1-WMI-START | BLOCKED. The local namespace connected. The start subscription returned `AccessDenied`, exit 3. |
| M3.1-WMI-STOP | BLOCKED. The local namespace connected. The separate stop subscription returned `AccessDenied`, exit 3. |
| M3.1-ETW-CONTROL | BLOCKED. `StartTraceW` returned Win32 error 5, exit 3. No session was created. |

The probe compiled with warnings treated as errors. All workers exited
within the watchdog. No matching child was launched and no trace provider
was enabled. Event receipt, filter behavior, ordering, cancellation of an
accepted subscription and loss detection remain untested. Windows 10 is
deferred. [Reproduction steps](../m3-1.md)

Runtime status remains unavailable for the tested account and configurations.
Source selection remains open pending a successful access and delivery
trial. Test other caller or source configurations independently.
